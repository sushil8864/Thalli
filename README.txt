# Romantic Love Website ❤️

Open `index.html` in Chrome/Edge.

## Quick edits
Search inside index.html for:
- Emma -> replace with her name
- Alex -> replace with your name
- `relationshipStart` -> change to your real date
- Replace the three image URLs with your own image URLs, or local image filenames.
- Replace the story, reasons and letter with your own text.

## Using local photos
Put your photos in the same folder and change:
<img src="https://...">
to:
<img src="myphoto.jpg">

No server is required for the basic version.
